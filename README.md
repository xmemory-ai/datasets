# Memory benchmarking datasets (xmemory)

This repository holds **memory benchmarking datasets** we used at **xmemory**. It is a **mixed bag**: cleaned-up exports, forked material, and semi-manually generated bundles sit side by side.

## Layout

- **Each dataset** has its **own top-level directory** under this repo.
- **Some** of those directories include **cooking and/or generation scripts** alongside the data.

## Format

We took the liberty to publish the datasets **in our own format**. Whether we will look into releasing the **framework we use internally** to run benchmarks is unclear—**far too much work**. Still, we figured most people who want to try these datasets will use **AI-assisted coding**, and our **YML structure is concise enough** that LLMs can figure it out without that runner.
